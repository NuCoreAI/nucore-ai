# Preferences

- The prompts log is always at `~/workspace/eisy-ai/logs/nucore.prompt.jsonl`.
- iox-vscode-plugin is in ../iox-vscode-plugin (github: https://github.com/universaldevices/iox-vscode-plugin)
- iox-plugin is in ../iox-plugin (github: https://github.com/universaldevices/ioxplugin)
If they are not already cloned, you can clone them using the following commands:
```bash
git clone git@github.com:universaldevices/iox-vscode-plugin.git ../iox-vscode-plugin
git clone git@github.com:universaldevices/iox-plugin.git ../iox-plugin
```
